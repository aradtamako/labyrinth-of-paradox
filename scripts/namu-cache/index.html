2. 관문 정보[편집]

 
역설의 미궁 관문 정보
M
메인 관문
중앙에 위치한 관문으로,
아래 관문으로 이동하거나 해당 라인의 외곽 관문 입장을 위해서는
반드시 격파가 필요하다.
R
유물 발굴 지대
해당 관문 격파 시 무작위 유물을 획득하며,
해당 유물을 특정 관문에 사용 시 대응되는 효과를 획득한다.
1개의 유물 발굴 지대는 최대 30회 입장 가능하다.
α
장비 창고 / 조율자의 흔적 / 거대한 장비 창고 / 조율자가 남긴 흔적
해당 관문 격파 시
지정된 장비/서약 결정 항아리 혹은 선택 상자를 획득할 수 있다.
이 문서에는 보상 정보가 그리스 문자(α, β, γ, ...)로 표시되어 있다.
K
미궁 보급 거점 (미궁 조사권)
해당 관문 격파 시 미궁 조사권 2개를 획득한다.
O
미궁 보급 거점 (외곽 입장권)
해당 관문 격파 시 외곽 입장권 2개를 획득한다.
H
어긋난 광휘의 순례
해당 관문 격파 시 계시 100 ~ 150개를 획득한다.
1
어긋난 생명의 순례
해당 관문 격파 시 가치가 보다 높은 보상을 획득한다.
이 문서에는 보상 정보가 숫자(1, 2, 3, ...)로 표시되어 있다.
A/L
이중 현상 / 종말이 드리운 나침반
해당 관문 격파 시 대응되는 던전의 토벌권을 획득할 수 있다.
각각 매주 용병단 레벨에 비례한 캐릭터 수만큼 격파할 수 있다.
D
이탈한 천해의 하늘
해당 관문 격파 시
매일 제공되는 계시 : 천해를 품은 하늘 토벌권 갯수가 1개 추가된다.
* 표시가 붙어있는 관문의 경우 미궁 조사권을 사용해 개방 시
상단 또는 하단에 있는 관문이 동시에 개방된다.
모든 관문은 최초 입장 이후 재도전/재입장 시에는 입장권을 소모하지 않는다.
